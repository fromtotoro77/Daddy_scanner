# 인식 엔진 연구 (2026-08-20)

- pagemodel.js : 로프트 원통 페이지 모델 + 좌표하강 피팅 + 행별 호길이 평탄화 (통합 대상 코드)
- gt.json : 사용자가 label_tool.html로 그린 정답 경계 (test_photos/1~4.jpg)
- gt_eval.py : 자동 채점 (외곽선 px + 평탄화 시프트% + 여백 기울기)
- gt_sheet.py : 시각 검증 시트 생성
- pagemodel_test2.py : 모델 렌더링 합성 파라미터 복원 테스트
