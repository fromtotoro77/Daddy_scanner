# 📄 Daddy Scanner

> 스마트폰 브라우저에서 책·문서를 촬영하고 **곡면까지 펴서** PDF로 만드는 스캐너
> **daddy 시리즈** — 설치 없이 웹 주소로 쓰는 우리집 앱 · *to miyeong*

**현재 버전: v1.5.1** (2026-08-22) · 배포 주소: https://fromtotoro77.github.io/Daddy_scanner/

## 사용법

1. 스마트폰 브라우저로 배포 주소에 접속 (홈 화면에 추가하면 앱처럼 사용, 이후 자동 업데이트)
2. 책 페이지를 **촬영** — 화면의 빨간 기준선과 네 모서리 꺾쇠에 페이지를 맞춰 찍으면 가장 정확합니다. 여러 장 연속 촬영 가능
   - 펼친 책 두 쪽을 한 번에: **펼침면** 모드(가운데 빨간 선 = 책등) → 좌·우 페이지가 각각 저장
   - 미리보기가 가로/세로로 어긋나면 **방향** 버튼
3. **페이지** 화면에서 확인 — 필요 없는 장은 선택 삭제, 순서 조정
4. 페이지를 눌러 **편집** — 매직컬러/흑백/밝기 보정, 영역보정(자동/수동 4모서리), 평탄화 옵션
5. **PDF 만들기** → 저장 또는 공유(카톡·메일 등)

모든 처리는 브라우저 안에서 이루어지며 **사진이 어디에도 전송되지 않습니다.**

## 주요 기능

- 📸 카메라 연속 촬영(고정 기준선 가이드) + 갤러리 사진 불러오기, 펼침면 양면 분할
- 📐 **페이지 모델 평탄화 엔진** (v1.5) — 말린 책 페이지를 원통 곡면+자세 모델로 맞춰 원본 해상도로 폅니다
  - 1단계: 테두리·연한 경계 증거로 종이 자세 추정 → 2단계: 외곽을 고정한 채 **글줄이 수평이 되는 자세** 선택
  - 3단계: **글줄 직교화** — 인쇄 괘선·글줄의 공통 기울기로 내용 전체를 회전하고, 남은 휨은 줄별 실측 + 전역 곡면으로 부드럽게 보정
  - 편집 화면 옵션: `글줄 직교화`, `좌측정렬 보정`(좌측 정렬이 아닌 책은 끄기)
- 🔍 문서 테두리 자동 감지·원근 보정(폴백), ✂️ 수동 4모서리 조정(조정한 모서리를 기준으로 모델 재피팅), 90° 회전
- 🎨 문서 필터: 매직컬러(그림자 제거)·흑백문서(적응형 이진화)·그레이·선명하게·원본 + 밝기/대비
- 🗂 페이지 관리: 다중 선택 삭제(실행취소), 순서 이동, 전체 필터 적용, 스와이프 화면 전환, 뒤로가기 버튼 화면 이동
- 📑 PDF 생성 3단계 품질 + Web Share 공유
- 💾 자동 저장(IndexedDB) — 브라우저를 닫아도 작업 복원
- 📴 PWA — 두 번째 접속부터 오프라인 동작, 새 버전 자동 반영

## 기술 스택

순수 정적 웹앱 (빌드·서버 없음). [OpenCV.js](https://docs.opencv.org/) + 자체 엔진 `pagemodel.js` + [jsPDF](https://github.com/parallax/jsPDF) (+ [jscanify](https://github.com/puffinsoft/jscanify) 최후 폴백) — 전부 CDN 로드.

- `app.js` — 앱 전체(촬영·감지·편집·PDF·저장)
- `pagemodel.js` — 평탄화 엔진(vFlat 특허 US10991081B1의 파라미터 페이지 모델을 무학습 최적화로 구현, 글줄 추출·회전·직교화 포함)
- `research/` — 엔진 연구 자료: 사용자 정답 라벨(`gt.json`, 7장)·자동 채점기(`gt_eval.py`)·시각 시트(`gt_sheet.py`)·라벨 도구(`label_tool.html`)·진단 스크립트. 엔진 변경은 이 채점기로 회귀 확인
